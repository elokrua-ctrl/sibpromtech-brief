# Фирменные файлы

Положите сюда оригинальный логотип из брендбука СИБПРОМТЕХ, например:

- `logo-white.svg` — для тёмного фона (шапка, стартовый экран);
- `logo.svg` — для светлого фона.

Затем укажите пути в `src/config/brand.ts`:

```ts
logoOnDark: 'brand/logo-white.svg',
logoOnLight: 'brand/logo.svg',
```

Пока пути пустые, в интерфейсе выводится название компании обычным текстом — логотип не перерисовывается.
